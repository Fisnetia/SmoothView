# SmoothView

网易云音乐的**界面动效**插件，用于 [BetterNCM](https://github.com/std-microblock/BetterNCM)。


## 功能

- 图片加载后按从上到下、从左到右依次淡入
- 歌单逐行渐显：打开时依次出现，滚动时新出现的行也淡入
- 鼠标滚轮丝滑滚动（触控板不受影响）
- 切换页面时新页面淡入
- 歌单吸顶标题栏毛玻璃
- 修正客户端偶尔出现的歌单缺行（往下滚时顶上几行不显示）

每一项都可以在插件设置里单独开关、调节。


## 安装

**方式一（推荐）**：在网易云的 BetterNCM 插件商店里搜索 `SmoothView` 安装。

**方式二（手动）**：下载最新Release的.plugin文件，放入插件文件夹


## 兼容性

- 网易云音乐 **3.1.40**（CEF / Chromium 91）实测通过
- 依赖 BetterNCM `>= 1.3.4`
